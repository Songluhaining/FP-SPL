# BankAccountTP单缺陷版本全方法对比

## 结论

本轮在73个单缺陷版本、1697个原本通过配置上完成统一评价，其中724个是假通过、973个是真通过。CLAP监督基准表现最好；PULP次之。新实现的五折弱监督学习赋权没有改善硬共享联合因果图，反而降低排序质量，因此当前不能作为优于基准的方法。

这一结论覆盖全部73个版本，不采用此前ID171单版本的有利结果替代全量结果。

## 统一实验范围

- 数据集：`4wise-BankAccountTP-1BUG-Full`；
- 缺陷版本：73；
- 评价对象：1697个原本执行通过的配置；
- 假通过：724，真通过：973；
- 由失败配置转换而来的377个假通过未纳入，因为它们在原始数据中仍执行失败；
- 基础特征缺陷：19个版本、342个配置，全部是假通过；
- 可选特征缺陷：54个版本、1355个配置，其中382个假通过、973个真通过；
- PULP报告560个疑似配置，其中基础特征组187个、可选特征组373个。

CLAP和新弱监督模型都按缺陷版本使用相同的固定散列五折。一个缺陷版本的全部配置只能出现在训练集或测试集的一侧。真假通过标签只用于CLAP监督训练以及最终评价；新方法训练不读取真假通过标签。

## 基准与当前方法

### CLAP监督基准

直接使用PULP仓库保存的CLAP属性计算实现，包含六项属性：测试多样性、覆盖不足、错误可验证性、正确性反映性、可疑语句包含可能性和依赖相似度。分类器与原实现一致，使用线性支持向量分类器。五折结果合并后：

| 指标 | 结果 |
|---|---:|
| 预测疑似配置 | 575 |
| 识别假通过 | 536 |
| 误报真通过 | 39 |
| 准确率 | 0.866 |
| 精确率 | 0.932 |
| 召回率 | 0.740 |
| F1 | 0.825 |
| 平均精确率 | 0.915 |
| 曲线下面积 | 0.914 |

五折各自的曲线下面积为0.942、0.922、0.851、0.938和0.970，没有单折失效。可选特征组的精确率为0.891、召回率为0.835、平均精确率为0.945、曲线下面积为0.983。

### PULP弱监督基准

磁盘中保存的逐配置结果在相同1697个配置上识别383个假通过，误报177个真通过：精确率0.684、召回率0.529、F1为0.597、准确率0.695、平均精确率0.726、曲线下面积0.685。

### 当前五折学习赋权

每条A/B联合因果证据使用所属留出折的两个模型得到测试等价势函数和故障屏蔽势函数。预先固定的配对分数为：

`联合因果可疑度 × 测试等价势函数 × 故障屏蔽势函数`

1557条配对全部完成评分，覆盖1259个配置。其余438个无可用反事实执行证据的配置保持0分。五折故障屏蔽代理任务的曲线下面积为0.878、0.869、0.876、0.891和0.908，但最终任务的总体平均精确率只有0.477、曲线下面积为0.628。

这表明代理任务表现良好不等于假通过识别有效。模型主要学会区分“执行结果是否翻转”，却没有可靠区分“真实故障被屏蔽”和“测试行为不等价、正常路径差异”等原因。

## 消融结果

在全部1697个配置上：

| 配对分数 | 平均精确率 | 曲线下面积 | PULP同全局预算下识别数 |
|---|---:|---:|---:|
| 仅联合因果分数 | **0.603** | **0.721** | **352** |
| 联合因果 × 测试等价 | 0.562 | 0.701 | 320 |
| 联合因果 × 故障屏蔽 | 0.501 | 0.637 | 245 |
| 两个势函数全部加入 | 0.477 | 0.628 | 251 |

两个学习势函数都没有带来增益，故障屏蔽势函数的负面影响更大。不能通过重新调整乘法权重后只报告更好结果；下一版需要改变学习目标。

## 理论解释与下一步

当前代理标签把“B失败、A通过”统一视为屏蔽正例，但这一现象至少包含三种不同机制：

1. A含有相同缺陷，但特征条件屏蔽了故障；
2. 两个测试并不真正等价，观察了不同语义；
3. A、B动态路径不同，但差异与缺陷无关。

仅凭结果翻转标签无法区分三者，模型会学到与最终真假通过标签不一致的捷径。下一版应以语句或路径级反事实一致性作为训练目标：保持联合因果后验作为主分数，只学习识别不可靠的配对并进行门控；训练正例需要同时满足测试判定一致、B侧故障路径可达、A侧对应语句和特征来源可解释，而不是只看通过/失败翻转。
