- 删除旧BRFL的Java因子图与插桩工程：src、lib、pylib、pyutils、pom.xml、原main.py及相关IDE配置。

- 删除旧的整配置剔除定位入口；当前仅保留独立报告状态修正。
- 从混合批处理文件中抽取当前实际调用的函数，分别归入data、detection、baselines、localization、experiments、evaluation。
- 原分散检查迁移到tests；两个实际使用的Java切片辅助程序迁移到tools/java。
- requirements.txt由旧工程整套环境精简为三个识别依赖，实验依赖单独保存。
- 删除result根目录不再使用的临时Python控制程序及生成缓存；保留工具下载、副本和历史中间数据。

旧工作树共有1074个跟踪文件路径被移除，其中仍有用的实现已迁移到新目录。详细迁移与删除目标见 `refactor-map.json`。官方VARCOP源码快照保持原样，不对第三方代码做此次裁剪。
