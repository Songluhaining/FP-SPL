# BankAccountTP单缺陷版本联合图实验

## 结论

当前联合反事实因子图具有实际区分能力，并提高了基础特征缺陷的召回率，但在全部73个单缺陷版本上尚未全面超过PULP。固定联合后验阈值0.55时，它识别出更多假通过配置，同时产生了更多误报；在与PULP相同的阳性预算下，命中数低于PULP。因此，当前实现适合作为经过纠正的研究原型，不能作为最终优越性结论。

## 实验范围

- 缺陷版本：73个；
- 原本通过的配置：1697个；
- 真实假通过：724个；
- 真实通过：973个；
- 原始执行子图：2019个；
- 成功组成的联合A/B执行配对：1557个；
- 至少具有一个可用联合配对的配置：1259个；
- 没有可用联合配对的配置：438个。

本次从历史插桩结果中读取语句、运行值、因子张量和观测结果，重新组成联合图并重新推理。没有复用旧版的单图后验。旧缓存缺少显式观测真假字段，但所有观测节点的旧值均严格为0或1，可以无歧义恢复观测结果。

历史实验中有620个配对找不到已有反事实测试，没有执行轨迹。本次将对应配置保留在全部评价对象中并赋零证据，没有调用620次DeepSeek。该处理给出当前执行覆盖条件下的保守结果。

联合方法使用预先固定的语句错误后验阈值0.55。该阈值没有在73个版本标签上重新选择。

| 指标 | 联合图 | PULP |

| 正确识别假通过 | 404 | 383 |
| 误报 | 250 | 177 |
| 漏报 | 320 | 341 |
| 准确率 | 0.664 | **0.695** |
| 假通过精确率 | 0.618 | **0.684** |
| 假通过召回率 | **0.558** | 0.529 |

联合图多识别21个假通过，但同时增加73个误报。当前固定判据提高了召回率，没有提高综合分类效果。

## 排序能力

| 指标 | 联合图连续后验 | PULP连续分数 |
|---|---:|---:|
| 平均精确率 | 0.603 | **0.726** |
| 曲线下面积 | **0.721** | 0.685 |

联合后验在整体成对区分上更好，但排名最前部分混入较多真通过配置，因此平均精确率明显较低。这个现象与固定阈值下误报较多一致。

当联合图使用与PULP相同的560个阳性预算时，命中352个假通过，精确率0.629；PULP命中383个，精确率0.684。按每个缺陷版本分别使用PULP预算时，联合图命中327个。结果表明差距不只是固定阈值造成的。

联合图在可选特征组只多识别1个假通过，却增加73个误报，是当前方法的主要问题。

## 原因判断

1. 当前配置分数取所有共享故障因果语句中的最大联合后验。共享语句越多，出现一个偶然高值的概率越大，可能造成误报。
2. 1516个历史配对属于内容相似测试，而不是完全相同测试。联合图目前把这些配对都作为可共同约束的执行，没有在概率因子中表达测试等价性的不确定程度。
3. 438个配置没有可用联合执行，分数为0，主要降低召回率。DeepSeek生成可以改善覆盖，但不能直接解决已有联合图上的250个误报。
4. 频谱先验来自B，并在缺失时由A补充。它与联合动态证据可能重复反映失败覆盖，需要通过消融实验检查是否重复计数。

## 后续改进约束

下一版不应再增加多个经验规则。更合理的单一改动是，在联合图中显式增加“测试行为是否等价”变量，让测试相似度控制A侧通过观测对共享语句的约束强度。完全相同测试形成强约束，相似或生成测试的不确定性由该变量传播。这样可以直接针对当前误报来源，同时保留联合概率推理这一核心。
