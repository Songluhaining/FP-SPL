# BankAccountTP全部73个缺陷版本实验

## 实验设置

- 数据集：`4wise-BankAccountTP-1BUG-Full`
- 缺陷版本：73
- 每个通过配置使用一个欧式距离最近的失败配置
- 已有测试最低相似度：0.55
- 每条失败测试检查前20个BRFL高可疑语句
- 未接入测试生成模型；找不到已有反事实测试时记为缺失
- 标签只在因果推理和排序全部完成后用于评价

评价对象包含1697个原本通过配置，其中724个是假通过、973个是真通过。标签中另有377个由失败配置转换的假通过；它们在原始数据集中仍会执行失败，未混入本轮评价。

## 严格差分规则

严格规则要求B侧语句可疑度至少0.55、语句在A中存在且执行、因果可达，并且B与A的可疑度差至少0.15。

没有语句同时满足全部条件，1697个配置均被标为“证据不足”。作为二分类结果，其假通过召回率为0。虽然保留的复合排序分数仍取得0.555的平均精确率和0.665的曲线下面积，但这个严格规则不能作为可用分类器。

原因是BRFL对A、B对应语句给出的后验值集中在中性先验附近：对齐语句的B侧平均可疑度为0.502，B减A的平均差为−0.0029。固定使用0.55和0.15会过滤掉几乎全部语句。

## 接近原始方案的规则

接近原始设想的规则使用BRFL中性先验0.5作为可疑度门槛，并要求语句在A中存在、实际执行且因果可达，不再要求较大的A/B后验差。

## 消融结论

- 只使用“源码存在且B侧可疑度至少0.55”时，精确率0.857，但召回率只有0.0166。
- 再要求实际执行和因果可达后，精确率0.750，召回率0.0083。
- 将可疑度门槛设为BRFL中性先验0.5后，召回率提高到0.834，但总体精确率降至0.550。
- 加入0.15的后验差门槛后，召回率变为0。

因而，动态图和因果可达关系能产生有用排序信号；BRFL绝对后验值和A/B差值暂时不足以直接给出可靠的固定分类门槛。

## 下一步

1. 将结果定位为排序任务，使用配置内相对可疑度、分位数或混合分布估计代替固定0.55门槛。
2. 提高反事实测试质量。当前只有45个完全一致测试，620个配对没有测试；应接入测试生成模型并严格验证B失败、A通过。
3. 使用多个最近失败配置，要求同一A获得跨近邻一致支持，以降低495个误报。
4. 对BRFL先验参数做稳定性分析，只保留跨参数重复出现的因果语句。
5. 单独构造377个由失败配置转换的假通过执行环境，避免把仍然失败的原始配置错误当成通过配置评价。

详细机器可读结果保存在实验输出目录的`evaluation.json`、`diagnostics.json`和`ablation.json`。
