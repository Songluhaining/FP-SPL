## 推断与比较协议

联合贝叶斯方法每个案例独立构造覆盖观测、初始化并推断，不接受真实故障数量、配置真假通过标签或其他案例的参数和后验。保持银行账户先导实验的稀疏参数1.5、9个触发率节点、阈值0.5；分别使用随机种子42和2026，平均两次风险作为最终分数。起始256个粒子和两轮条件更新，候选风险最大差超过0.05时，依次增加到1024个粒子三轮、4096个粒子四轮；仍不稳定的案例单独报告。种子一致不是严格收敛证明。

有监督分类（CLAP）和正例与未标注学习（PULP）调用本地公开实现，保留此前核验过的兼容与等价加速。每个系统的双缺陷层与三缺陷层分别按版本名的固定摘要排序划分五折，同一案例全部配置在同一折，每个候选恰好获得一次折外预测；前者仅获得训练折标签，后者只把可见失败配置视作正例。此划分保证版本不交叉，但不宣称基础变异在训练与评价间完全不重叠。

本轮比较的是当前联合方法，历史单缺陷表中的“贝叶斯诊断”仍指此前四步方法，合并表明确保留方法名称和缺陷层，不把两者混称为同一个模型的统一实验。

## 评价与核验

全部联合预测保存之后才生成评价真值。主结果是“相对基准标签的识别结果”：注入位置存在于启用特征的产品中即为阳性；另报缺陷位置实际执行次数为正的标签。分别单列“至少一个故障在基础特征”和“没有基础特征故障”，同时保留“全部故障均在基础特征”及其补集，避免多缺陷混合案例被误当成没有基础特征故障。这里不把分类识别写成实际补测确认。

三种方法使用同一原本通过配置分母；记录成功评分、证据不足、混淆矩阵、精确率、召回率、调和平均值、准确率、平均精确率及每案例前10%检查预算命中数。独立脚本从粒子重算联合风险、从原始报告和变异日志重建标签，并检查候选无遗漏无重复、分折独立及全部统计。

案例派生文件存于原案例 `.fp_research/multifault_joint`；切片缓存存于同缺陷层 `.fp_research/slice-cache`，不另复制数据集。原始文件在基线准备前后及最终验收时比较摘要。失败记录保留在对应案例中，修复后重跑；只有全部案例完成并核验后才生成完成凭据。

## 本轮兼容修正

1. 成员概率理论上为1时，浮点加权求和可能得到1.0000000000000002；在明确检查误差不超过1e-12后，将其截到合法边界。
2. 条件更新中把通过证据线性求和，仅对受当前变量影响的失败观测计算非线性项；随后将通过项完全汇总为每个候选的覆盖次数，只保存失败模式的生存概率矩阵。这是相同似然的等价计算，不改变先验、推断方式或模型；两个电梯真实样例两次优化前后的分数及粒子逐值相同，见 `optimization-check.json`。
3. 仅在工具、源码和执行语句集合均匹配时复用旧实验的静态切片，不复用标签或模型参数；已有新切片时进一步核对完整集合。六个代表案例的两种基线全部特征在复用前后逐值相同，见 `cache-equivalence-check.json`。
4. 本机实际使用英特尔数学库；仅设置另一种数学库的线程变量不能限制它。最终运行明确把每进程数值计算限制为一个线程，避免8个推断进程各开20个线程；六例预测、后验粒子及12份基线特征表在限制前后逐值相同，见 `thread-equivalence-check.json`。全部案例按这一最终环境重算，静态切片通过原始输入摘要和工具摘要恢复。

## 可重复运行

在仓库根目录的命令行中，设置 `PYTHONUTF8=1`、`OPENBLAS_NUM_THREADS=1`、`MKL_NUM_THREADS=1`、`OMP_NUM_THREADS=1`、`NUMEXPR_NUM_THREADS=1`；基线准备另设置 `FP_SLICE_BACKEND=indexed`、`FP_SLICE_WORKERS=8`。Python解释器为 `D:/SoftInstall/python.exe`。并发数只影响耗时，不参与模型计算。

```text
python -m unittest fp_research.checks.test_joint_fault fp_research.checks.test_multifault_partitions
python -m fp_research.multifault_cache
python -m fp_research.multifault_study fit --smoke --workers 3
python -m fp_research.multifault_study prepare --smoke --workers 3
python -m fp_research.multifault_study fit --workers 8
python -m fp_research.multifault_study prepare --workers 8
python -m fp_research.multifault_study labels
python -m fp_research.multifault_study classify --method CLAP
python -m fp_research.multifault_study classify --method PULP
python -m fp_research.multifault_study evaluate
python -m fp_research.checks.verify_multifault
python -m fp_research.checks.repeat_multifault_baseline --method CLAP
python -m fp_research.checks.repeat_multifault_baseline --method PULP
```

也可在启动推断与特征准备后运行 `python -m fp_research.multifault_finish`，它会等全部案例准备成功后再完成分类和独立验收，不会把部分结果写成完整结果。
